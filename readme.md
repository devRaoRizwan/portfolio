# Rizwan Portfolio

## Run locally

This is a React + Vite project. Install a current Node.js LTS release, then run:

```bash
npm install
npm run dev
```

Open the local address Vite prints (normally `http://localhost:5173`).

## Before publishing

Replace the placeholder email and social/profile links in `src/main.jsx` with Rizwan's real contact details and resume URL.
